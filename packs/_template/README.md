# Template

Copy this directory to `packs/<code>/`, replace `xx` with the two-letter language code, then
translate `ui.json` and `dialogue.json`. Register the language in `catalog.json`.

`ui.json` must keep every key from `packs/en/ui.json`. `dialogue.json` keeps the original
format: `event`, optional `tone`/`speaker`/`weight`, and `text` with the same placeholders.
